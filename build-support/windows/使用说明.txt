LinkForge v0.1.0-beta.1 — Windows x64 便携试用版

开始使用
1. 将整个 ZIP 解压到有写入权限的目录，例如下载目录或桌面。
2. 双击 LinkForge.exe。无需安装 Python、uv、Node.js 或 Chromium。
3. 填写学习通课程学习页地址、模型服务商、模型和您自己的 API Key。
   测验需要支持图片输入的模型。模型服务可能按供应商规则收费。
4. 保留默认浏览器用户目录，或选择一个专供 LinkForge 使用的目录。
5. 点击“开始运行”，在弹出的浏览器中手动登录学习通。
6. 页面就绪后程序自动处理已支持的课程任务。使用过程需要联网。

文件与更新
- 不要在 ZIP 中直接运行，不要单独移动 EXE 或删除 _internal。
- 运行日志位于 LinkForge.exe 同级 logs 文件夹，可点击“打开日志文件夹”。
- 默认登录数据保存在 %LOCALAPPDATA%\LinkForge\browser-profile。
- 常用配置保存在本机 Qt 设置中；API Key 使用 Windows 凭据管理器保存。
- 更新时先关闭 LinkForge 和它启动的浏览器，将新版解压到新的文件夹。
  使用相同 Windows 账户及浏览器用户目录，可继续使用原配置与登录数据。
  网站登录过期时仍需重新登录；升级前可保留旧版和必要的日志。
- 凭据库不可用时，本次仍可运行，但下次可能需要重新输入 API Key。

停止与已知限制
- “停止”会请求安全退出，当前任务可能需要完成后才停止。
- 支持范围主要为学习通视频、PDF/电子书、单选/多选/判断测验及讨论。
- 模型答案不保证正确，页面变化或未支持模块可能导致停止。
- 当前尚无可靠的整门课程完成判定，到课程末尾可能报错停止。
- 部分任务记录只保存在本次运行中，尚无完整持久化断点恢复。
- 本候选包需完成干净 Windows 环境和真实课程验收；以发布页验收记录为准。

问题反馈
点击“用户反馈”，描述操作步骤和错误，并上传问题截图及对应日志。
日志位于程序旁边的 logs 文件夹。上传前检查并删除敏感信息。
不要上传 API Key、Cookie、账号密码、完整课程链接或浏览器用户目录。
测验截图和讨论上下文会发送给您配置的模型服务。

开发者诊断（普通使用不需要）
LinkForge.exe --self-test <报告JSON的绝对路径>
此操作使用临时配置和本地页面验证界面、内置浏览器、登录数据持久化。
它会在系统凭据库写入并删除一个独立的临时测试条目，不读取用户 API Key。
报告和界面截图保存在指定位置；详细异常保存在 logs 中。
