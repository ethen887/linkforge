# 凭据与用户数据

- 不提交 API Key、Cookie、Token、密码、浏览器登录状态或用户隐私数据。
- 浏览器用户目录包含登录状态，应保留在本机，不上传、提交或分享。
- 日志、截图、Issue、PR 和终端输出中的敏感信息必须脱敏；不提供完整课程链接或未经检查的用户数据。
- API Key 使用系统原生凭据库保存，不引入明文文件回退。
- 普通常用配置通过 `QSettings` 保存，API Key 通过 `CredentialStore` 保存；修改配置项时保持
  两者分离，凭据库不可用时允许本次运行继续，不将底层异常中的秘密写入日志或界面。
- 开发示例与测试夹具使用占位值，不新增硬编码的真实课程链接、认证参数或用户标识。
- 修改与模型交互的功能时，明确哪些截图或上下文会发送给配置的模型服务。
- GUI 日志摘要与文件日志是不同输出路径；新增日志或错误消息时检查两条路径，
  不假定界面已脱敏就意味着文件日志也已脱敏。
- 本机凭据、系统设置和其他既有目录的修改遵循 `D:\Dev\AI\AI.md` 中的范围约束。

用户侧配置与隐私说明见 [README.md](../README.md#配置与隐私)。
