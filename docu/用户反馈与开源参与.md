# 用户反馈与开源参与

GUI 每次启动会显示一次非模态提醒，介绍反馈与开源贡献入口。选择“稍后再说”、按 Esc 或关闭提醒后仍可正常使用；隐藏再显示同一主窗口不会重复提醒。

主界面的“用户反馈”和“参与开发”按钮在课程运行期间也保持可用。网页仅在用户点击后通过系统默认浏览器打开。

## 反馈表单

当前公开填写链接：[LinkForge 用户反馈](https://mhhvya3d.jsjform.com/f/NqrEmH)。启动提醒中的“反馈问题”和主界面的“用户反馈”按钮使用同一个链接。

如需更换链接，在 `src/linkforge/ui/community.py` 中更新 `FEEDBACK_FORM_URL`，使用金数据的公开 HTTPS 填写链接，不使用管理后台或结果查看链接。之后重新运行或重新打包应用。链接被清空时会显示入口暂未开放提示。

表单应设置为所有人可填写，不要求登录或身份验证。发布前用无痕窗口实际验证文字提交和截图上传均无需登录；附件能力、额度及通知规则以表单服务当前配置为准。

建议收集反馈类型、问题描述、操作步骤、App 版本，以及选填的截图和联系方式。App 不会自动上传课程地址、配置、凭据、日志或截图，也不会将这些内容拼接到填写链接。

## 开源贡献

- 项目仓库：https://github.com/ethen887/linkforge
- 贡献指南：https://github.com/ethen887/linkforge/blob/main/CONTRIBUTING.md

提醒邀请开发者提出需求、修复问题或开发自己需要的功能，并说明先通过 Issue 讨论需求和实现方案，再提交 Pull Request。

无法打开默认浏览器时会显示地址，用户可以复制并手动访问。反馈入口未配置或链接打开失败不影响课程运行。
